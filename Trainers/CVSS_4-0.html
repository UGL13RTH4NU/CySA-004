CVSS 4.0 Cheat Sheet

Exam focus — what matters
  • Read vectors. Know the metric abbreviation, what it measures, and what each value means.
  • Know the four groups: Base, Threat, Environmental, Supplemental.
  • Know the split inside Base: Exploitability (AV, AC, AT, PR, UI) and Impact (VC, VI, VA, SC, SI, SA).
  • Do not treat CVSS-B as full risk. It is technical severity; Threat and Environmental context improves prioritization.
  • Supplemental metrics do not alter the CVSS score.
Source correction: CertMaster attributes CVSS development/oversight to NIST. CVSS is owned and managed by FIRST. NIST/NVD is an important publisher/consumer of CVE and CVSS data.

AC vs AT: AC asks what the attacker must do to defeat security-enhancing conditions. AT asks what preexisting deployment/runtime condition must already be present.
Base Impact values

Each CIA impact uses H / L / N. Prefix tells you which system suffers the impact:

  • V = vulnerable system: VC, VI, VA.
  • S = subsequent system: SC, SI, SA.
v4 trap: v3.x Scope (S) was retired. v4 explicitly scores impact to the vulnerable system and subsequent system instead.
Threat + Environmental

Threat: only E — Exploit Maturity: X Not Defined, A Attacked, P Proof-of-Concept, U Unreported.

Environmental: CR/IR/AR plus modified Base metrics. Modified metrics override their Base counterpart for the local environment; X means use the Base value.

Worst-case default: E:X is treated like E:A for scoring. Do not read “Not Defined” as “safe.”
Advanced v4 detail: MSI and MSA can use S = Safety to represent predictable human-safety consequences in the local environment.

CVSS vs EPSS
  • CVSS: technical severity and vulnerability characteristics; 0.0–10.0.
  • EPSS: ML-based probability that a published CVE will be exploited in the wild in the next 30 days; score 0–1 plus percentile; refreshed daily.
Use together: “How bad could it be?” (CVSS) + “How likely is exploitation soon?” (EPSS) is much more useful for remediation prioritization than either signal alone.
v3.1 → v4.0 traps
  • Attack Requirements (AT) is new in v4.
  • User Interaction now uses None / Passive / Active.
  • Scope is retired; use V-system and Subsequent-system impacts.
  • Temporal is renamed Threat; only Exploit Maturity remains.
  • Supplemental is a new optional group.

Legacy scanners and study material may still show CVSS 3.1. For this Module 7 trainer, use the v4.0 structure taught by CertMaster.

  • Subsequent systems: C Low, I Low, A None.
  • Automatable; manual recovery; Medium response effort; Green provider urgency.
  • No explicit Threat or Environmental metrics.
