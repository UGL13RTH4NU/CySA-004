LOLBins Cheat Sheet

Core idea: the binary can be legitimate and signed. The suspicious part is the behavior: unusual network access, decoding, remote execution, persistence, or unexpected child processes.
Windows — Dion core set
LOLBINExam recognition cue
PowerShell-EncodedCommand, execution-policy bypass, IEX/WebClient downloads, odd parent such as Office.
certutil.exeCertificate utility abused to download or Base64 decode files.
WMI / WMICRemote execution, lateral movement, WMI event-subscription persistence; Sysmon 19/20/21 are high-value clues.
mshta.exeTrusted Windows HTML Application host used to execute HTA/JavaScript/VBScript and proxy execution.
regsvr32.exeTrusted registration utility abused to proxy-execute DLL/scriptlet content and bypass application controls.
Dion memory aid: W-C-M-R — Windows scripting via PowerShell, Certutil, WMI, and registry-adjacent/proxy tools such as mshta/regsvr32.
Linux — Dion core examples
ToolExam recognition cue
curlCommand-line data transfer; suspicious when a shell downloads a payload to a temp/user path.
wgetCommand-line downloader; same high-value chain: network connection → new file → execution.
nc / netcatGeneral TCP/UDP connection/listener utility; can create raw socket channels and support remote shells.
Platform trap: these are Dion exam buckets, not absolute compatibility boundaries. Some tools are cross-platform or available on modern Windows.

Behavior-based detection clues
  • Built-in process suddenly makes an external network connection.
  • Download is followed by file creation in Temp, /tmp, AppData, or another user-writable location.
  • Encoded/obfuscated command-line arguments appear.
  • Trusted binary spawns a scripting engine or unexpected shell.
  • Office/browser/email process launches PowerShell or command shell.
  • WMI persistence appears in Sysmon Event IDs 19, 20, or 21.
