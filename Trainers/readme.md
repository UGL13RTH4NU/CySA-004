# CySA+ CS0-004 Interactive Trainers

Browser-based study trainers for the CompTIA Cybersecurity Analyst (CySA+) CS0-004 V4 exam. Each is a self-contained HTML file — no install, no dependencies. Open directly in a browser via the links below.

## Live trainers

| Trainer | Topic |
| --- | --- |
| [CVSS 4.0](https://ugl13rth4nu.github.io/CySA-004/Trainers/CVSS_4-0.html) | CVSS v4.0 vector strings, metric groups, and score interpretation |
| [File Systems](https://ugl13rth4nu.github.io/CySA-004/Trainers/File_Systems.html) | NTFS, FAT, ext, APFS — structure, artifacts, forensic relevance |
| [Frameworks](https://ugl13rth4nu.github.io/CySA-004/Trainers/Frameworks.html) | NIST CSF, MITRE ATT&CK, Cyber Kill Chain, Diamond Model, and related |
| [Logging](https://ugl13rth4nu.github.io/CySA-004/Trainers/Logging.html) | Log sources, formats, and analyst-relevant fields |
| [OT](https://ugl13rth4nu.github.io/CySA-004/Trainers/OT.html) | Operational Technology — ICS/SCADA, protocols, and security considerations |
| [SOC Roles](https://ugl13rth4nu.github.io/CySA-004/Trainers/Soc_Roles.html) | Tier 1/2/3, IR team composition, and responsibility boundaries |
| [Tools](https://ugl13rth4nu.github.io/CySA-004/Trainers/Tools.html) | Security tool identification, categorization, and scenario-to-tool matching |

## Usage

Click any link above to open the trainer in your browser. Trainers are static — no data leaves your device, and progress is not saved between sessions.
