Core display filters — Dion
FilterWhat it isolates
ip.addr == [IP]Packets where the IP is either source or destination.
tcp.port == [port]TCP packets where the port is either source or destination.
http.requestHTTP request packets.
http.request.method == "POST"HTTP POST requests.
dnsDNS traffic.
tcp.flags.syn == 1 and tcp.flags.ack == 0Initial SYNs: SYN set, ACK not set.
Exam cue: PBQs may show a filter and ask what it reveals, or give the traffic requirement and ask for the correct filter.

Capture filter vs display filter
Capture filterDisplay filter
WhenBefore/during collectionAfter packets are captured
SyntaxBPF-style: host, port, tcp, udp, not, and, orWireshark fields such as ip.addr, tcp.port, http.request
RiskNonmatching packets are never captured.Packets remain in the capture; only the view changes.
Trap: You cannot recover packets that a capture filter excluded. A display filter is reversible.
Three panes + investigation features
  • Packet List: summary rows for each packet.
  • Packet Details: per-layer decoded fields.
  • Packet Bytes: raw hex + ASCII.
  • Follow TCP Stream: reconstructs the full conversation/session content.
  • Statistics → Protocol Hierarchy: fast protocol-mix overview.
  • Statistics → Conversations: communication-pair overview.
  • File → Export Objects: extract transferred HTTP/SMB/FTP files.

Default packet coloring — technical supplement
Wireshark coloring rules are customizable and theme-sensitive. These samples represent the built-in default rule families; learn the pattern, not an exact monitor shade. Rules are evaluated top-down and the first match wins.
SampleDefault rule
TCP — light lavender
UDP — light blue
HTTP — light green
ARP — pale tan
ICMP — pale pink/lilac
TCP SYN/FIN — gray
Bad TCP / checksum errors — dark warning row with red/pink text
TCP RST — dark red warning row

Memory hooks / traps
  • ip.addr / tcp.port = either direction; .src/.dst = one direction.
  • http.request and dns are presence filters — no comparison operator required.
  • HTTP method is a string, so "POST" needs quotes.
  • Initial SYN = SYN 1 AND ACK 0.
  • Capture-filter BPF words look very different from Wireshark display-filter fields.
